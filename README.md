# EVA Assistant - Голосовой ассистент

EVA Assistant - это продвинутый голосовой ассистент с поддержкой wake-word детекции "ЕВА", который может выполнять команды через голосовое управление.

## Основные возможности

### ✨ Ключевые функции
- 🎙️ **Постоянное распознавание wake-word "ЕВА"** - асинхронное обнаружение активационного слова
- 🌐 **Оффлайн и онлайн режимы** - работа с интернетом и без него
- 🖥️ **Кросс-платформенность** - поддержка Windows x64 и macOS с автоматическим определением
- 🎯 **Нечеткое сопоставление команд** - точность совпадения 65% через fuzzywuzzy
- ⌨️ **Эмуляция ввода** - pydirectinput-rgx для Windows, pynput для macOS/Linux
- 📝 **Настраиваемые команды** - словарь команд с возможностью редактирования
- 📊 **Визуальные индикаторы** - эквалайзер для отображения уровня аудио
- 🎨 **Современный GUI** - интерфейс на PySide6 с темной темой

### 🔧 Дополнительные возможности
- 📋 **Редактор команд** - визуальный выбор сочетаний клавиш и настройка таймингов
- 🖱️ **Управление процессами** - выбор активного процесса и взаимодействие с ним
- 📝 **Система логирования** - подробное логирование всех операций
- ⏹️ **Принудительная остановка** - безопасное завершение работы ассистента
- 🔊 **Индикация в реальном времени** - полоса эквалайзера для визуализации распознавания

## Установка и запуск

### Требования
- Python 3.8+
- Windows x64 или macOS (Linux - частичная поддержка)
- Микрофон для голосового ввода

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
python main.py
```

## Использование

### Первый запуск
1. Запустите приложение командой `python main.py`
2. В главном окне выберите режим работы (онлайн/оффлайн)
3. Настройте пороги распознавания при необходимости
4. Нажмите "Запустить EVA"

### Основные команды по умолчанию
- **"Копировать"** → Ctrl+C
- **"Вставить"** → Ctrl+V  
- **"Сохранить"** → Ctrl+S
- **"Отменить"** → Ctrl+Z
- **"Новая вкладка"** → Ctrl+T
- **"Закрыть вкладку"** → Ctrl+W
- **"Переключить окно"** → Alt+Tab

### Создание новых команд
1. Откройте "Редактор команд" из главного окна
2. Нажмите "Новая команда"
3. Заполните основные параметры:
   - ID команды (уникальный идентификатор)
   - Название команды
   - Описание
4. Добавьте фразы для распознавания
5. Настройте действия (клавиши, текст, задержки)
6. Сохраните команду

### Настройка горячих клавиш
1. В редакторе команд перейдите на вкладку "Основные"
2. Кликните в поле "Горячая клавиша"
3. Нажмите нужную комбинацию клавиш
4. Нажмите Enter для подтверждения или ESC для отмены

## Конфигурация

### Настройки распознавания
- **Порог wake-word**: 50-95% (по умолчанию 65%)
- **Порог команд**: 50-95% (по умолчанию 65%)
- **Режим работы**: Онлайн/Оффлайн/Авто

### Файлы конфигурации
- `commands.json` - словарь команд
- `logs/eva_YYYYMMDD.log` - файлы логов
- Настройки сохраняются автоматически

## Решение проблем

### Проблемы с микрофоном
- Проверьте права доступа к микрофону
- Убедитесь, что микрофон не используется другим приложением
- Перезапустите приложение

### Проблемы с распознаванием
- Увеличьте громкость микрофона
- Снизьте пороги распознавания
- Проверьте интернет-соединение для онлайн режима

### Проблемы с выполнением команд
- Убедитесь, что целевое приложение активно
- Проверьте права доступа (особенно на macOS)
- Используйте принудительную остановку при зависании
