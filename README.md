# ЕВА — голосовой ассистент (офлайн/онлайн)

Минимальная реализация по плану:
- офлайн (Vosk) и онлайн (Google Speech via SpeechRecognition) режимы
- модульная архитектура с автодетектом платформы (Windows/macOS/Linux)
- постоянное распознавание вейк-ворда «ЕВА» и асинхронный режим команд
- выполнение команд с нечетким сопоставлением (порог по умолчанию 65)
- симуляция ввода с клавиатуры (pydirectinput/pyautogui)
- словарь команд (JSON) и редактор команд в GUI (PySide6)
- логирование в файл и отображение распознанной речи в GUI
- индикатор работы и визуализация уровня сигнала (эквалайзер-полоса)
- модуль выбора активного процесса (базовая реализация)
- возможность принудительной остановки ассистента в GUI

## Установка

1) Python 3.10+
2) Установите зависимости:
```bash
pip install -r requirements.txt
```

3) (Офлайн режим) Скачайте модель Vosk для русского языка и распакуйте в `models/vosk-ru`:
- Модели: `https://alphacephei.com/vosk/models`
- Рекомендуется `vosk-model-small-ru-0.22` или новее

Итоговая структура:
```
workspace/
  models/
    vosk-ru/
      ... файлы модели ...
```

## Запуск
```bash
python -m eva_assistant.gui.app
```

В GUI выберите режим (офлайн/онлайн), нажмите Старт. Кнопка Стоп — принудительная остановка. Редактор команд — для добавления/изменения фраз и клавиш.

## Примечания
- На Windows используется `pydirectinput` (при наличии), иначе `pyautogui`.
- На macOS для активации приложений используется `osascript`. Некоторые функции могут требовать дополнительных разрешений доступности.
- Если офлайн-модель не найдена, будет уведомление в GUI/логах.
- Порог нечеткого сопоставления можно менять в настройках/JSON.
